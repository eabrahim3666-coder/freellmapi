# FreeLLMAPI — Render-এ 24/7 ডিপ্লয় গাইড (ফ্রি)

এই ফোল্ডারে যা আছে:

- `render.yaml` — Render Blueprint ফাইল। এটা Render-কে বলে: অফিসিয়াল FreeLLMAPI ডকার ইমেজ (`ghcr.io/tashfeenahmed/freellmapi:latest`) থেকে একটা **ফ্রি Web Service** বানাও, সিঙ্গাপুর রিজিয়নে, আর `ENCRYPTION_KEY` নিজে থেকে জেনারেট করে রাখো (তাই রিপোতে কোনো গোপন কী থাকে না)।

ডিপ্লয় হবে Dockerfile বিল্ড ছাড়াই — সরাসরি প্রি-বিল্ট ইমেজ, তাই ডিপ্লয় ২-৩ মিনিটে শেষ।

---

## ধাপ ১ — GitHub রিপোজিটরি বানাও (তুমি, ২ মিনিট)

1. যাও: https://github.com/new
2. Repository name: `freellmapi-render` (যেকোনো নাম চলবে) → **Public** বা **Private** দুটোই ঠিক আছে → **Create repository**
3. নতুন রিপোতে **"uploading an existing file"** লিংকে ক্লিক করো
4. এই ফোল্ডারের `render.yaml` ফাইলটা ড্র্যাগ করে ছেড়ে দাও → **Commit changes**

> রিপোতে `render.yaml` ফাইলটা **রুটে** (গোড়ায়) থাকতে হবে — Render এটাই খোঁজে।

## ধাপ ২ — Render-এ ডিপ্লয় (আমি করব)

1. https://render.com → **Get Started** → **GitHub দিয়ে সাইন আপ** (সবচেয়ে সহজ), অথবা ইমেইল দিয়ে
2. Render-কে তোমার GitHub অ্যাকাউন্টে ঢোকার অনুমতি দাও (শুধু রিপো পড়ার জন্য)
3. তারপর **আমাকে রিপো URL দাও** (যেমন `https://github.com/tomar-name/freellmapi-render`), আর এই ব্রাউজার উইন্ডোতে Render-এ লগইন করা রাখো — বাকি ক্লিকগুলো আমি করে দেব

হাতে করতে চাইলে (আমি না থাকলে): Render ড্যাশবোর্ড → **+ New** → **Blueprint** → রিপো সিলেক্ট → **Apply/Deploy**। শেষ হলে URL পাবে: `https://freellmapi-xxxx.onrender.com`

## ধাপ ৩ — প্রথম সেটআপ (তুমি, ৫ মিনিট)

1. `https://freellmapi-xxxx.onrender.com` খোলো → ইমেইল + পাসওয়ার্ড দিয়ে প্রথম অ্যাকাউন্ট বানাও
   - ক্লাউডে থাকায় **প্রথম অ্যাকাউন্ট বানাতে সেটআপ কোড লাগবে** — সেটা Render ড্যাশবোর্ডের **Logs** ট্যাবে দেখতে পাবে (`First-run setup code: ...`)
2. **Keys** পেজ → আবার সব প্রোভাইডারের key যোগ করো (ক্লাউড ডেটাবেস নতুন, তাই লোকাল key এখানে আসবে না)
3. **Keys** পেজের হেডার থেকে **নতুন unified key** (`freellmapi-...`) কপি করো — এটাই এখন থেকে সব জায়গায় ব্যবহার হবে

## ধাপ ৪ — ১৫ মিনিটে ঘুমাবে না, ২৪/৭ অন থাকবে (তুমি, ৩ মিনিট)

Render ফ্রি ইন্সট্যান্স ১৫ মিনিট নিষ্ক্রিয় থাকলে ঘুমায়। ফ্রি পিং সার্ভিস দিয়ে জাগিয়ে রাখা যায়:

**UptimeRobot (রেকমেন্ডেড, ফ্রি):**
1. https://uptimerobot.com → ফ্রি অ্যাকাউন্ট
2. **+ Add New Monitor** → Monitor Type: **HTTP(s)** → URL: `https://freellmapi-xxxx.onrender.com/` → Interval: **5 minutes** → Save

**বিকল্প:** https://cron-job.org → ফ্রি অ্যাকাউন্ট → নতুন cron job → URL-টা ১০ মিনিট পর পর হিট করো।

> ⚠️ Render ফ্রি প্ল্যানে মাসে ৭৫০ ইন্সট্যান্স-আওয়ার। একটাই সার্ভিস ২৪/৭ চালালে লাগে ~৭৪৪ ঘণ্টা (৩১ দিনের মাসে) — **ঠিকঠাক ফিট করে, কিন্তু আর কোনো ফ্রি সার্ভিস চালু করা যাবে না।**
> ⚠️ ২৪/৭ জাগিয়ে রাখা সাধারণ প্র্যাকটিস, তবে Render-এর ফ্রি প্ল্যানের মূল ডিজাইনই হলো ঘুমানো — ভবিষ্যতে নিয়ম বদলালে হয় পেইড প্ল্যান, নাহয় VPS-এ যেতে হবে (তোমার প্ল্যানেও ছিল)।

| সেটিং | মান |
|---|---|
| Base URL | `https://freellmapi-xxxx.onrender.com/v1` |

## জানা দরকার (সৎ সীমাবদ্ধতা)

1. **ডিস্ক সাময়িক (ephemeral):** Render ফ্রি টিয়ারে পার্সিস্টেন্ট ডিস্ক নেই — **প্রতিবার রিডিপ্লয়/রিস্টার্টে SQLite ডেটাবেস মুছে যাবে**, মানে প্রোভাইডার key গুলো আবার যোগ করতে হবে। সমাধান: (ক) মেনে নাও, (খ) $০.২৫/মাসে ১GB ডিস্ক (পেইড অ্যাড-অন), (গ) পরে VPS-এ গেলে সমস্যা থাকবে না। চাইলে আমি DB-কে বাইরের স্টোরেজে ব্যাকআপ করার ব্যবস্থাও (FREEAPI_DB_BACKUP_URL) করে দিতে পারি।
2. **ফ্রি ইন্সট্যান্স = ০.১ CPU, ৫১২MB RAM** — সাধারণ চ্যাট/মার্কেটিং কপি রাইটিংয়ের জন্য যথেষ্ট, কিন্তু একসাথে ৫০-১০০টা রিকোয়েস্ট ছুঁড়লে ধীর লাগবে। ব্যাচ কাজে concurrency কম রাখো।
3. **আপডেট:** ইমেজ-ভিত্তিক সার্ভিস নিজে নিজে নতুন ভার্সন টানে না। নতুন ভার্সন চাইলে Render ড্যাশবোর্ড → সার্ভিস → **Manual Deploy → Deploy latest reference**।
4. **লেটেন্সি:** সিঙ্গাপুর রিজিয়ন থেকে ইমেজ চলবে, রিকোয়েস্ট যাবে প্রোভাইডারদের সার্ভারে — লোকালের চেয়ে কিছুটা বেশি ms, কিন্তু কাজের সমস্যা নয়।
5. **লোকাল সেটআপ সাথে থাকুক:** তোমার PC-র অটো-স্টার্ট করা সার্ভারটা মজুদ হিসেবে চালুই থাকবে (পোর্ট 3001)। Render ডাউন হলে লোকালে ফলব্যাক করতে পারবে।

## ফাইলটা আসলে কী বলে (render.yaml)

```yaml
services:
  - type: web
    name: freellmapi
    runtime: image
    plan: free
    region: singapore
    healthCheckPath: /
    image:
      url: ghcr.io/tashfeenahmed/freellmapi:latest
    envVars:
      - key: ENCRYPTION_KEY
        generateValue: true
```

- `runtime: image` → প্রি-বিল্ট ইমেজ (বিল্ড মিনিট খরচ নেই, দ্রুত ডিপ্লয়)
- `plan: free` → ফ্রি ইন্সট্যান্স (০.১ CPU / ৫১২MB)
- `region: singapore` → বাংলাদেশ থেকে সবচেয়ে কাছের রিজিয়ন
- `generateValue: true` → Render নিজেই শক্তিশালী এনক্রিপশন কী বানিয়ে গোপনে রাখে; রিপোতে কোনো সিক্রেট থাকে না
- পোর্ট কিছু সেট করতে হয় না — Render নিজে `PORT` env দেয়, FreeLLMAPI সেটা পড়ে নিজে থেকে ঠিক পোর্টে বাঁধে
